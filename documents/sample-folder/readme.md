# ドキュメント管理システム

## 概要
このシステムは、GitHub Pagesを使用した静的サイトでドキュメントを管理・表示するためのシステムです。

## 機能
- **ファイル一覧表示**: フォルダ構造でのファイル管理
- **検索機能**: ファイル名による検索
- **テキスト表示**: .txt、.mdファイルの表示
- **PDF表示**: PDFファイルの埋め込み表示

## 対応ファイル形式
- `.txt` - プレーンテキスト
- `.md` - Markdown形式
- `.pdf` - PDFドキュメント

## 使い方
1. 左側のフォルダ一覧からファイルを選択
2. 選択したファイルが右側に表示される
3. 検索バーでファイルを検索可能

## 技術仕様
- **HTML5** + **CSS3** + **Vanilla JavaScript**
- **PDF.js** - PDF表示ライブラリ
- **GitHub Pages** - ホスティング

## カスタマイズ
`documents/config.json`ファイルを編集することで、
表示するファイル構造をカスタマイズできます。

**重要**: WordファイルはPDFに変換してからアップロードしてください。
